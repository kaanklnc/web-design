# Web Programming — Sıfırdan Adım Adım Kodlama Labı

Dr. Mesut ÜNLÜ Web Programming ders slaytlarına ve vize kodlama konularına (HTML5 Form Yapıları, CSS Seçiciler, Kutu Modeli ve Layout) göre sıfırdan öğrenenler için hazırlanmış etkileşimli HTML5 + CSS3 laboratuvar simülasyonu.

## Özellikler

- **16 Adımlık Sıralı Müfredat (4 Modül):**
  - **Modül 1:** HTML5 İskeleti, Metin Biçimlendirme, Bağlantılar (`<a>`), Görseller (`<img>`), Listeler ve Tablolar (`colspan`/`rowspan`)
  - **Modül 2 (Vize Odağı):** Form İskeleti (`action`, `method`, `target`, `fieldset`, `legend`), `label` ↔ `input` bağlantısı, `radio`, `checkbox`, `select`, `textarea`, `datalist`, `output`
  - **Modül 3 (Vize Odağı):** CSS Kural Yapısı, Temel Seçiciler (`*`, `element`, `#id`, `.class`, grup), Attribute Seçiciler (`[attr^="val"]`, `$=`, `*=`), Pseudo-class (`:hover`, `:first-child`) ve Pseudo-element (`::first-letter`, `::before`)
  - **Modül 4:** Renkler, Yazı Tipleri (`px` / `em`), Kutu Modeli (`margin`, `border`, `padding`, `outline`), Semantik Düzen (`<header>`, `<nav>`, `<aside>`, `<footer>`), Flexbox, CSS Grid ve Final Vize Simülasyonu
- **Canlı Tarayıcı Önizlemesi:** Yazdığınız HTML ve CSS anında tarayıcı çerçevesi içinde çalışır; `<title>` etiketi sekme başlığını, form gönderimleri ise yöntem bilgisini canlı olarak gösterir.
- **Etkileşimli Laboratuvar Araçları:** Seçici Röntgeni, İnteraktif Kutu Modeli ve HTTP `GET` vs `POST` Simülatörü.

## Yerelde Çalıştırma

Herhangi bir kurulum gerektirmez. `index.html` dosyasını doğrudan tarayıcıda açabilir veya yerel bir sunucu ile çalıştırabilirsiniz:

```bash
python -m http.server 8080
```

Ardından tarayıcıda `http://localhost:8080/` adresini açın.
